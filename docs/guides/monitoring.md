# Monitoring and troubleshooting

:::{note}
This guide is still being written. Until it lands, the design is explained in [Watchdog and collector](../concepts/watchdog-collector.md).
:::

`domyn-swarm status` reports per-replica health read from the watchdog database, alongside the load-balancer endpoint. Job-level commands are `job list`, `job status`, `job wait` and `job cancel`.
